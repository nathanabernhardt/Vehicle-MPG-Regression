This regresson project utilizes car data to predict the continuous variable of miles per gallon. Notebook sections include exploratory data analysis, visualization EDA, and machine learning. Ridge and Random Forest Regression models are evaluated with the final model being chosen based on cross validation scoring. Regression metrics including R2, MSE, and MAE are calculated to determine model performance. Finally, feature evalulation is completed to determine which features possessed the highest predictive power of the MPG target variable.
